Projects & Case Studies

Selected hardware and software projects engineered by Dasari Venkata Panakala Chitti Babu:

AI-Powered Road Hazard Intelligence (eMudhra Hackathon 2026)

Neuro-symbolic road hazard detection system fusing IMU vibration analysis (MPU6050), CNN-based visual classification (YOLO/MobileNet), and GPS-based multi-vehicle clustering. Features a rule-based confidence-cascade escalation model (log → warn → alert) to convert multi-vehicle detections into driver warnings and authority alerts. Cost-estimated hardware architecture evaluated for ESP32, MPU6050, NEO-6M GPS, and ESP32-CAM.

ESP32-Based Health Monitoring System

Real-time health monitoring system using ESP32, interfacing multiple physiological sensors for live vital parameter acquisition. Features wireless data transmission for remote monitoring and end-to-end hardware-software integration, testing, and debugging.

Hand Sign / Word Sign Detection System

Computer vision pipeline utilizing MediaPipe for 21 hand landmark extractions from live video input, coupled with a CNN-based classification model for accurate gesture and word-sign recognition.
